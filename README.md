# Портфолио — шаблон сайта для фрилансера

Адаптивный многостраничный сайт-портфолио на чистом HTML/CSS/JS — **без сборки и зависимостей**.
Трёхъязычный (Русский · English · Svenska) с контентом-заглушкой: подставьте свои данные и публикуйте.

Структура: главная-хаб + три страницы направлений — **«Сайты и приложения»**, **«Android-разработка»**
и **«AI/ML»** — и раздел **«Заметки»** с техническими статьями.

## Что внутри

```
portfolio/
├── index.html             # Главная: hero, направления, о себе, услуги, навыки, как начать, контакты
├── web.html               # «Сайты и приложения»: карьерный путь, проекты, навыки, контакты
├── android.html           # «Android-разработка»: факты, что я делаю, проекты, open source, контакты
├── ai.html                # «AI/ML»: опыт, проекты, навыки, open source, контакты
├── notes.html             # «Заметки»: список статей
├── notes/
│   ├── hermi-offline-voice-assistant.html        # статья о Hermi (ru/en/sv)
│   └── medvoice-offline-clinical-dictation.html  # статья о MedVoice (ru/en/sv)
├── assets/
│   ├── media/              # демо-видео, постеры и скриншот (Hermi, MedVoice)
│   ├── css/styles.css      # стили и токены дизайна (цвета, шрифты, отступы)
│   └── js/
│       ├── i18n.js          # словарь переводов (ru/en/sv) и переключатель языка
│       └── script.js        # тема, меню, анимации, форма
├── favicon.svg             # иконка вкладки
└── README.md
```

Все страницы делят одни и те же CSS, JS, навигацию (Главная · Сайты и приложения · Android · AI/ML ·
Заметки · Контакты), подвал и переключатели темы и языка. На страницах без формы (заметки) пункт
«Контакты» ведёт на `index.html#contact`. Гамбургер-меню включается при ширине окна ≤ 1180px —
иначе шесть пунктов навигации не помещаются в одну строку.

### Возможности
- **Три языка** (RU / EN / SV) с переключателем в шапке; выбор сохраняется в `localStorage`
  и применяется на всех страницах.
- Тёмная и светлая темы с переключателем (тоже сохраняется в `localStorage`).
- Плавная прокрутка, анимации появления при скролле, счётчики и шкалы навыков.
- Форма контактов без бэкенда (собирает письмо в почтовом клиенте), кнопка записи на звонок по ссылке.
- Полная адаптивность: мобильный, планшет, десктоп + гамбургер-меню.
- Доступность: семантическая разметка, aria-атрибуты, видимый фокус, поддержка `prefers-reduced-motion`.

### Как работают переводы (i18n)

- У каждого текстового элемента есть атрибут `data-i18n="ключ"`. Скрипт `i18n.js` подставляет
  строку из словаря в выбранном языке. Для плейсхолдеров — `data-i18n-ph`, для `aria-label` —
  `data-i18n-aria`, для `title` — `data-i18n-attr-title`.
- Заголовок вкладки и `meta description` задаются на `<body>` через `data-title-key` / `data-desc-key`.

**Изменить перевод:** найдите ключ в объекте `DICT` в `assets/js/i18n.js` и отредактируйте строку
для `ru`, `en` и `sv`.

**Добавить новый текст:** задайте элементу `data-i18n="мой.ключ"` в HTML и добавьте `"мой.ключ"`
во все три локали в `i18n.js`.

**Добавить ещё один язык:** скопируйте целиком блок одной локали (например `en`) внутри `DICT`,
переведите значения, добавьте код языка в массив `LANGS` и добавьте кнопку
`<button data-lang="xx">XX</button>` в переключатель `.lang-switch` в шапке каждой страницы.

**Статьи (`notes/*.html`)** переводятся иначе: длинный текст хранится прямо в HTML, по блоку на язык —
`<div class="prose" lang="en" data-lang-content="en" hidden>…</div>`. `i18n.js` показывает блок
текущего языка и скрывает остальные; без JavaScript виден русский (у `en`/`sv` стоит `hidden`).
Атрибут `data-lang` для этого не используйте — он занят кнопками переключателя языка.
Заголовок, дата, время чтения и карточка в `notes.html` — обычные ключи (`noteN.title`, `noteN.excerpt`,
`title.noteN`, `note.date`, `note.read3`).

### Как добавить проект, страницу или заметку

- **Проект:** скопируйте блок `<article class="project-card">` в `web.html` или `ai.html`,
  задайте новые ключи `data-i18n` для заголовка/описания и добавьте их в `i18n.js`.
- **Новая страница-специализация:** скопируйте `web.html`, поменяйте `data-page`, `data-title-key`,
  `data-desc-key`, контент и ссылку в переключателе направлений на главной. Добавьте пункт в
  навигацию на всех страницах и отметьте активную ссылку через `aria-current="page"`.
- **Заметка:** скопируйте файл из `notes/`, замените текст в трёх блоках `data-lang-content`, дату
  (`<time datetime>` и ключ даты) и время чтения (≈ 200 слов в минуту), добавьте ключи `noteN.*` / `title.noteN`
  в `i18n.js` и карточку `<article class="note-card">` в `notes.html`. Ссылки из `notes/` начинаются с `../`.

### Демо-видео и скриншоты
Медиафайлы лежат в `assets/media/`:
- `hermi-demo.mp4` (1272×720) + `hermi-demo-poster.jpg` — в начале статьи о Hermi (`#demo`) и превью карточки Hermi;
- `medvoice-demo.mp4` (574×1280, вертикальное) + `medvoice-demo-poster.jpg` и `medvoice-screenshot.png` —
  в начале статьи о MedVoice (`#demo`, рядом, не шире 300px; на телефоне друг под другом, до 360px)
  и превью карточки MedVoice.
Ссылки «Смотреть демо →» в карточках ведут на `notes/…html#demo`. Подписи и alt-тексты — ключи `media.*` в `i18n.js`
(для `alt` используется атрибут `data-i18n-alt`).

Заменить видео: положите новый файл под тем же именем (H.264/AAC MP4, до 720p по высоте для горизонтальных
видео, `-movflags +faststart`, желательно до ~15 МБ) и обновите постер, например:
`ffmpeg -i in.mp4 -vf "scale=-2:720" -c:v libx264 -crf 26 -preset slow -c:a aac -b:a 96k -movflags +faststart out.mp4`
и `ffmpeg -ss 3 -i out.mp4 -frames:v 1 -q:v 4 poster.jpg`. Видео с YouTube можно вставить вместо `<video>`:
`<iframe src="https://www.youtube-nocookie.com/embed/ID_ВИДЕО" title="…" loading="lazy" allowfullscreen></iframe>`.

### Open source
Блок «Open source» на `android.html` и `ai.html` ссылается на репозитории Hermi, MedVoice, CarDiagnostics,
HinnerJag и CopilotMoneyAndroid. В нём же есть два скрытых пункта (`<li hidden data-oss-slot="sdk|apk">`):
«LocalEdgeAI SDK (Maven Central)» и «Демо-APK». Когда они будут опубликованы, впишите реальную ссылку в `href`
(например, страницу артефакта на central.sonatype.com или релиз на GitHub с APK) и удалите атрибут `hidden` —
на обеих страницах.

### Запись на звонок
Рядом с «Обсудить проект» (главная, статьи) и в блоке контактов есть кнопка «Записаться на звонок»
(`data-booking`). Пока ссылки нет, кнопки скрыты. Чтобы включить, вставьте ссылку на свой календарь
(Calendly, Cal.com, Google Calendar Appointment и т. п.) в начало `assets/js/script.js`:
`var BOOKING_URL = "https://cal.com/ваш-логин/30min";` — кнопки появятся на всех страницах.

### Цвета и шрифты
Все цвета — это CSS-переменные в начале `assets/css/styles.css` (блок `:root` и `[data-theme="light"]`).
Меняйте акцент (`--accent`, `--accent-2`, `--accent-3`), нейтральные тона или шрифты
(ссылка на Google Fonts в `<head>` + переменные `--font-sans` / `--font-mono`).

### Подключение формы обратной связи
Бэкенда нет, поэтому форма работает через почтовый клиент: `script.js` (блок «6. ФОРМА БЕЗ БЭКЕНДА»)
проверяет поля и открывает `mailto:artemkhateev.ai@gmail.com` с темой «Проект: <имя>» (на языке сайта)
и готовым текстом письма. Без JavaScript срабатывает `action="mailto:…"` самой формы.
Адрес задаётся константой `CONTACT_EMAIL` в `script.js` и в атрибуте `action` формы на каждой странице.

Чтобы принимать заявки на сервер (без почтового клиента), например через [Formspree](https://formspree.io):

1. Зарегистрируйтесь и создайте форму — получите endpoint вида `https://formspree.io/f/abcwxyz`.
2. В каждом `<form id="contact-form">` замените `action` на этот endpoint, `method="POST"`, уберите `enctype`.
3. В `assets/js/script.js` удалите блок «6. ФОРМА БЕЗ БЭКЕНДА», чтобы форма отправлялась напрямую.

Альтернативы: Netlify Forms, Getform, собственный backend.

## Как опубликовать

### GitHub Pages
1. Запушьте файлы в ветку `main` (или `gh-pages`).
2. Settings → Pages → Source: ветка `main`, папка `/root` → Save.
3. Через минуту сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.

### Netlify
1. Netlify → **Add new site → Import from Git** (или перетащите папку на app.netlify.com/drop).
2. Build command оставьте пустым, Publish directory — корень репозитория. Deploy.

### Vercel
1. Vercel → **Add New → Project** → импортируйте репозиторий.
2. Framework Preset: **Other**, build/output не требуются. Deploy.

Поскольку сборки нет, можно просто открыть `index.html` в браузере локально.
