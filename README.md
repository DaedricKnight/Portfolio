# Портфолио — шаблон сайта для фрилансера

Одностраничный адаптивный сайт-портфолио на чистом HTML/CSS/JS — **без сборки и зависимостей**.
Готовый шаблон с русскоязычным контентом-заглушкой: подставьте свои данные и публикуйте.

Ориентирован на специалиста уровня **AI/ML &amp; Software Engineer**, но легко адаптируется под любую сферу.

## Что внутри

```
portfolio/
├── index.html            # разметка всех секций
├── assets/
│   ├── css/styles.css     # стили и токены дизайна (цвета, шрифты, отступы)
│   └── js/script.js       # тема, меню, анимации, форма
├── favicon.svg            # иконка вкладки
└── README.md
```

### Секции
Навигация (sticky) · Hero · Обо мне · Опыт (таймлайн) · Проекты (сетка карточек) ·
Навыки · Отзывы · Контакты (форма + прямые ссылки) · Подвал.

### Возможности
- Тёмная и светлая темы с переключателем (выбор сохраняется в `localStorage`).
- Плавная прокрутка, анимации появления при скролле, счётчики и шкалы навыков.
- Полная адаптивность: мобильный, планшет, десктоп + гамбургер-меню.
- Доступность: семантическая разметка, aria-атрибуты, видимый фокус, поддержка `prefers-reduced-motion`.

## Как настроить под себя

Все места для замены помечены в коде комментарием `<!-- ЗАМЕНИТЕ: ... -->`.
Откройте `index.html` и пройдите по секциям:

1. **Имя и заголовок** — тег `<title>`, логотип-инициалы (`brand-mark` и `favicon.svg`), имя в Hero.
2. **Hero** — ценностное предложение, подзаголовок, ссылка на резюме (положите PDF в репозиторий
   и укажите его в кнопке «Скачать резюме»), социальные ссылки, цифры в блоке статистики.
3. **Обо мне** — текст о себе и список специализаций. Фото: замените блок `photo-placeholder`
   на `<img src="assets/img/photo.jpg" alt="Имя Фамилия">` (создайте папку `assets/img`).
4. **Опыт** — три карточки таймлайна (роль, компания, период, достижения).
5. **Проекты** — три карточки (заголовок, описание, теги, ссылки «Демо»/«Код»).
6. **Навыки** — группы чипов и шкалы с процентами (`data-level`).
7. **Отзывы** — два отзыва (можно удалить секцию, если не нужна).
8. **Контакты** — email, Telegram, GitHub, LinkedIn и форма (см. ниже).

### Подключение формы обратной связи
Статический сайт не отправляет письма сам. Самый простой путь — [Formspree](https://formspree.io):

1. Зарегистрируйтесь и создайте форму — получите endpoint вида `https://formspree.io/f/abcwxyz`.
2. В `index.html` у `<form id="contact-form">` замените `action="#"` на свой endpoint и оставьте `method="POST"`.
3. В `assets/js/script.js` удалите блок «6. ДЕМО-ОБРАБОТЧИК ФОРМЫ», чтобы форма отправлялась по-настоящему.

Альтернативы: Netlify Forms, Getform, собственный backend.

### Цвета и шрифты
Все цвета — это CSS-переменные в начале `assets/css/styles.css` (блок `:root` и `[data-theme="light"]`).
Поменяйте акцент (`--accent`, `--accent-2`, `--accent-3`), нейтральные тона или шрифты
(ссылка на Google Fonts в `<head>` + переменные `--font-sans` / `--font-mono`).

## Как опубликовать

### GitHub Pages
1. Запушьте файлы в ветку `main` (или `gh-pages`).
2. Settings → Pages → Source: ветка `main`, папка `/root` → Save.
3. Через минуту сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.

### Netlify
1. Netlify → **Add new site → Import from Git** (или перетащите папку на app.netlify.com/drop).
2. Build command оставьте пустым, Publish directory — корень репозитория. Deploy.

### Vercel
1. Vercel → **Add New → Project** → импортируйте репозиторий.
2. Framework Preset: **Other**, build/output не требуются. Deploy.

Поскольку сборки нет, можно просто открыть `index.html` в браузере локально.
